# Notes on model files 

Several models are supplied: 


## Our final models (generic)

`Davis2026.osim` - Our final IT band model grafted onto RajagopalLaiUhlrich2023. This is the generic model you should use for general purpose investigation.   
`Davis2026_DGF.osim` - Final model with all muscles replaced with De Groote/Fregly muscles. Use this for Moco simulations.  
`Eng2015_replica.osim` - the exact replica of the Eng 2015 model. **Do not use** for general purpose simulation (has wrapping surface issues; see manuscript).  


## Source and scaled models  

For the results we also need generic and scaled versions of several "off the shelf" models, so these are included as well.
